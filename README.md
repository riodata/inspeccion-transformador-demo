# Inspección Remota Inmersiva — Transformador de distribución

Demostración de Río Data Análisis: modelo 3D navegable de un transformador de distribución relevado con dron, con acceso a las fotografías aéreas correspondientes a cada vista.

Modelo de carácter ilustrativo, sin calibración métrica. La ubicación del activo se omite.

Desarrollado por [Río Data Análisis](https://riodataanalisis.com.ar).
